# GitHub + deployment checklist

## Publish on GitHub
1. Sign in to GitHub and create a new **public** repository named `medical-insurance-cost-prediction`.
2. Do not initialize it with a README if you will upload this prepared folder as-is.
3. Upload all files in this folder (not the ZIP itself), keeping `app.py` and `requirements.txt` at repository root.
4. Commit the files and open the repository's main page.
5. Capture a genuine browser screenshot showing the repository name and file list.

## Deploy on Streamlit Community Cloud
1. Sign in to Streamlit Community Cloud using the GitHub account that owns or can access the repository.
2. Create/deploy an app from the repository's default branch.
3. Main file path: `app.py`.
4. Wait for the app to finish building; fix any displayed dependency/runtime errors if they occur.
5. Open the public app URL and submit both sample test cases.
6. Capture genuine browser screenshots of the app form and prediction output.
